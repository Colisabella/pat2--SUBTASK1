# The research of Morse Code

## What is Morse Code?
Morse code is a communication system that uses dots (..) and dashes (--) to represent letters, numbers, and symbols.

## History of Morse code
Morse code developed in the 1830s and 1840s by Samuel Morse and Alfred Vail, it was created to ensure long distance communication via the electrical telegraph. The system become important in military communication and emergency signals.
Samuel Morse declared "If the presence of electricity can be made visible in any part of the circuit, I see no reason why intelligence may not be transmitted instantaneously by electricity."

## How the Morse code works
The system assigns a unique sequences of short and long signals to each letter of the alphabet and each number.
Morse code uses:
              - Dots (.)
              - Dahes (-)

## The importance of Morse code
- Accessibility for people with disabilities
- Emergencies communication ( SOS ... --- ... )
- Weak signal communication
- Educational tool for Rhythm and Pattern Recognition
